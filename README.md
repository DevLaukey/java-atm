## Overview
`java-atm` is a Java-based application simulating an Automated Teller Machine (ATM). It is designed to help users understand and interact with basic ATM functionalities such as balance checking, deposits, and withdrawals. This project serves as an educational tool, introducing key programming concepts, OOP principles, and enhanced user experience in Java applications.

### Why java-atm?
In an era where digital banking is becoming increasingly important, understanding the backend functionalities of services such as ATMs can be invaluable. `java-atm` provides a practical approach for learners and developers to explore the operational aspects behind financial transactions without needing real-world banking data or risking actual funds.

### Core Features
- 💰 **Balance Inquiry**: Allows users to check their account balance easily.
- 🏦 **Deposits**: Provides functionality to deposit funds into a virtual account.
- 💸 **Withdrawals**: Enables secure cash withdrawals from the account.
- 🛡️ **User Authentication**: Ensures a secure login mechanism for account access.
- 📊 **Transaction History**: Displays a summary of recent transactions for review.

## Getting Started
Follow these instructions to set up the project locally on your machine.

### Prerequisites
- Java Development Kit (JDK) installed on your machine.
- A Java IDE like IntelliJ IDEA or Eclipse (optional, but recommended).

### Installation
1. **Clone the Repository**
   ```bash
   git clone https://github.com/DevLaukey/java-atm.git
   cd java-atm
   ```

2. **Compile the Project**
   - Navigate to the project directory where the `Main.java` file is located.
   - Use the following command to compile the Java files:
   ```bash
   javac Main.java
   ```

3. **Run the Application**
   ```bash
   java Main
   ```

### Usage
Once the application is up and running, follow the on-screen instructions to navigate through the ATM functionalities. You can perform operations such as checking your balance, making deposits, and withdrawing money.

### Testing
Currently, there are no automated tests set up for `java-atm`. However, users can manually test the functionality by interacting with the application as described in the usage instructions above.
